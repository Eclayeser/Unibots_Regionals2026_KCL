*Make a service that is started automatically on Pi*

In terminal:

    sudo nano /etc/systemd/system/robot.service

---------------------------------------------------------
[Unit]
Description=Robot Listener Service
After=network.target

[Service]
ExecStart=/usr/bin/python3 #PATH_TO_YOUR_SCRIPT#/main.py
WorkingDirectory=#PATH_TO_YOUR_SCRIPT#
StandardOutput=journal
StandardError=journal
Restart=always
User=#MY_USERNAME#
SupplementaryGroups=gpio video
KillMode=control-group

[Install]
WantedBy=multi-user.target
---------------------------------------------------------

TO ENABLE AND START THE SERVICE:

    sudo systemctl daemon-reload
    sudo systemctl enable robot.service
    sudo systemctl start robot.service


TO CHECK STATUS:

    sudo systemctl status robot.service

READ LOGS:

    journalctl -u robot.service -f
