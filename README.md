# Unibots
Repository for code to test the robot for the Unibots competition.
Eventually, the code combines to create an autonomous robot.

Separate files:
=> Servos testing file: servos should rotate as desired
=> Movement testing file: motors should spin cohesively to produce direction of movement (rotation, forward, backwards)
=> Balls detection testing file: image analysis should return coordinates of all balls seen, as well as their type (ping pong or steel one) and estimated distance to it
=> AprilTags detection testing file:
=> Upgraded ball detection file: additionally, prefer balls that sit further away from foreign objects (walls, other robots)
